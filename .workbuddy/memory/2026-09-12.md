## 次日 00:20 出厂默认改成「隐藏到托盘」

用户原话「程序初始将隐藏到托盘设置为默认」。关键是**区分三种"没值"**，别混成一类：

| 情形 | 行为 | 依据 |
| --- | --- | --- |
| 库里没存过这一行（`Ok(None)`） | **Hide（默认）** | 产品口径：磅房那台机器本来就该一直开着；托盘有图标，回得来 |
| 没登录 / 库没就绪 / 读失败 | Exit | 安全口径："想退退不掉"比"想留没留住"严重 |
| 存了但值认不出来 | Exit | 不认识的写法宁可退回"退得掉"，不猜 |

- `window.rs`：`impl CloseBehavior` 新增 `pub const DEFAULT: Self = Self::Hide;` 与
  `as_str()`（`CloseBehavior::parse` 保持不变，认不出仍回 Exit —— 默认值与解析兜底是两回事）。
  `close_behavior()` 的 match 从 `_ => Exit` 拆成 `Ok(None) => DEFAULT` / `Err(_) => Exit`。
- 前端 `window-native.ts`：`DEFAULT_CLOSE_BEHAVIOR: CloseBehavior = "hide"`；
  **`parseCloseBehavior` 的兜底从"回落默认"改成回落 `"exit"`**（原来认不出就回默认，
  改成默认=hide 后会出现"库里是垃圾、Rust 走退出、界面却高亮隐藏"的骗人设置页）。
